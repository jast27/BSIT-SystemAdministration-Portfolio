# Week 2 – Enterprise Infrastructure Planning

## Project Overview

This project focuses on planning the IT infrastructure of ABC Startup Solutions. It covers the company's business scenario, hardware and software requirements, network infrastructure, and enterprise network design.

## Learning Objectives

- Analyze the IT requirements of a small business.
- Prepare hardware and software inventories.
- Design an enterprise network topology.
- Create professional technical documentation.
- Practice infrastructure planning and network design.

## Company Scenario

ABC Startup Solutions is a newly established software development company with 20 employees. The company operates on a single office floor and requires an IT infrastructure to support its daily operations.

The company currently has no existing computers, server, network infrastructure, Internet connection, or security policies. The project focuses on planning the required infrastructure from scratch.

## Challenges Encountered

One of the main challenges encountered was organizing the network topology and ensuring that the required devices were logically connected and clearly labeled. Creating a readable and professional network diagram also required careful layout and adjustment.

## Reflection
